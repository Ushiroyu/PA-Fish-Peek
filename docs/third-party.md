# 第三方组件

| 范围 | 用途 |
| --- | --- |
| `winhttp.dll`、`.doorstop_version`、`doorstop_config.ini` | Doorstop 引导与配置 |
| `dotnet/` | CoreCLR 与托管运行库 |
| `BepInEx/core/` | BepInEx、Harmony、Il2CppInterop 等依赖 |
| `BepInEx/unity-libs/` | 配套 Unity 库 |
| `BepInEx/interop/` | 与具体游戏构建关联的生成互操作程序集 |
| `src/PAFishPeekPlugin/` | 本项目插件源码 |

第三方组件适用各自的许可与再分发条件。插件源码、配套运行时与游戏相关互操作程序集分别管理。
