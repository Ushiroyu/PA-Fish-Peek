## 第三阶段：Agent 应用与评测

- [ ] 接入模型 Provider，完成理解问题、选工具、执行与结果校验的有限循环。
- [ ] 设置步数、超时和成本预算，失败时返回确定性查询或明确错误。
- [ ] 结构化条件使用规则和数据库；文档与故障资料按需要增加 RAG 与来源引用。
- [ ] 建立人工核对的黄金问题集，覆盖错误前提、缺失数据和工具失败。
- [ ] 分别衡量规则正确性、工具成功率、任务完成率、答案依据、延迟与成本，注明样本量和口径。
- [ ] 增加 Trace、回放、提示注入与工具权限边界测试。
- [ ] 部署服务与演示界面，记录使用反馈和修复闭环。

先完成可演示闭环，再按需求考虑跨会话 Memory、多智能体和复杂向量检索。当前静态表不是向量知识库，玩家临时缓存不是 Agent 长期记忆。
