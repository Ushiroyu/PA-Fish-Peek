# 后续规划

## 使用体验

- 优化多人同时咬钩时的玩家映射、提示顺序和重复消息处理。
- 持续适配鱼竿、鱼种、钓点和天气变化。
- 丰富显示选项、快捷键与日志诊断信息。
- 按游戏版本整理兼容性、场景测试与更新记录。

## 模块与数据

- 提取独立的候选规则模块，集中管理等级、地点、竿型和环境匹配。
- 为候选解释保留输入条件、筛选过程、排序依据和回退原因。
- 增加事件快照与离线回放，支持同条件复现与回归检查。
- 使用版本化数据存储管理鱼种、鱼竿、地点和天气信息。

## 工具接口演进

- 增加版本差异查询和跨版本兼容报告。
- 扩展现有六个只读 MCP 工具的查询维度。
- 持续维护工具 Schema、错误协议和回归样例。
- 丰富基于真实反馈整理的查询案例。

## 智能查询与评测演进

- 扩大现有领域与中文检索回归集，覆盖更多版本和异常条件。
- 按具体模型与问题集记录引用质量、工具选择、延迟和消耗。
- 基于调用 Trace 优化检索排序、问题澄清与失败恢复。
- 根据使用场景评估语义检索、跨轮状态与批量分析能力。

各项规划围绕可演示、可解释、可复现的使用场景推进。
