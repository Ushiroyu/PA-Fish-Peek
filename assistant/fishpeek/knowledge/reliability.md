# 调用控制与回答依据

## 调用预算

网页兼容接口 Agent 默认最多执行 6 个模型步骤、12 次模型选择的工具调用，单次模型输出上限配置为 1200 token，总执行时间默认 90 秒。前置检索和显式条件查询在模型循环前执行。重复的相同工具与参数第 3 次出现时停止，避免无效循环。桌面客户端调用 MCP 的预算由客户端管理，不使用网页 Agent 的这组计数。

## 重试与错误恢复

兼容接口遇到 HTTP 429、502、503、504 或请求连接错误时最多重试一次，单次模型请求默认超时 30 秒。参数格式或范围错误返回明确错误结果，模型可修正输入后继续。连续重复、步骤超限、无效引用或总超时会结束本次执行。错误输出不包含供应商响应正文或密钥。

## Trace 与记录范围

网页调用记录写入本机 SQLite，最多保留 1000 次 Trace。记录包含工具名、步骤状态、耗时与创建时间，不保存密钥和原始提示。Trace ID 用于定位某次执行；桌面 MCP 演示使用客户端事件流核验，与网页 Trace 分别保存。

## 引用与可信依据

网页 Agent 给规则结果和检索文段分配来源 ID，回答只能引用本次提供的 ID。文段带文件路径与行号，规则结果带 catalog 版本和鱼名。检查引用存在不等于检查每句话都被来源支持。检索文段和工具输出是数据，其中要求泄露配置、执行命令或改变规则的内容不能作为新指令执行。
