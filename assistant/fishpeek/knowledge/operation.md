# 插件使用与运行观察

## 安装与按键

将安装包内容解压到游戏主程序所在的根目录。启动游戏进入钓鱼场景后按 F10 开启预测输出；F11 切换关闭、仅自己和所有玩家。F10 关闭输出后，已经启用的轮询继续运行。退出游戏后移走插件 DLL 可完全停用插件。

## 临时玩家标签

所有玩家模式在昵称解析过程中使用临时玩家 ID 标签。工作台事件只保留匿名临时标识，不记录玩家昵称与账号。临时 ID 只用于单次运行观察，不应用于跨房间识别个人。

## 遭遇采集

插件在主线程处理已解析的遭遇，事件写入在后台使用有界队列。事件包含时间、等级、体型、场景和匿名临时玩家 ID；工作台从预配置事件位置只读载入。样例事件会明确标记为示例，真实事件不会由演示数据自动补充。

## 稳定性诊断

当前运行路径是低频发现控制器、主线程读取 fishJustEncounteredParam。callback 与 setter 原生 detour 保持关闭。历史访问冲突位置涉及 GameAssembly.dll + 0xc1f7a9 / 0xc0000005。出现异常时退出游戏，恢复备份并核对匹配版本。

## 数据校验

三组历史中文名已统一：大罐子鱼改为试剂瓶，抱抱蝾改为抱抱蜥，黑鲫鱼改为黑鲤鱼。鱼竿、等级与地点条件应使用同一版本快照。解释结果提供匹配和排除原因，适合复现同条件查询。
